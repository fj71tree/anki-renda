# 学習リポジトリ (Webアプリケーション開発)

## このリポジトリの目的

このリポジトリの目的は以下の2点です。

- Webアプリケーションの設計・開発・運用を学び、実務での貢献につなげる
- 学習内容を公開することで、自身のスキルを可視化する

## このリポジトリで行うこと

- 暗記カードアプリの設計・開発・運用
- フロントエンド・バックエンド・インフラを含めた学習
- ユーザー価値を意識した開発・改善
- セキュリティ・コストを意識する
- 実務で携わる可能性や需要を意識した技術選定
- 学習過程の記録

技術を学習するだけではなく、実務に求められるユーザー価値やセキュリティを意識することで、より実務に近い設計・開発・運用を学びます。

## このリポジトリで行わないこと

- 個人開発サービスとしての事業展開
- 収益化を意識した開発

アプリケーション自体は公開しますが、収益化やサービスの成長を目的とした個人開発ではありません。
学習を目的とした技術選定や機能開発があるため、あくまでポートフォリオとして公開します。
